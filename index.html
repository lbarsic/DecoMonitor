Owner TP-Link ID password

This is the password for the owner TP-Link ID, the same one the Deco’s own page asks for. It is not the Wi-Fi password, and it is not your Google password. Signing in to the Deco app with Google does not create this password.

To create one: open the Deco app, log out, and on the sign-in screen tap Forgot password. Use the email address behind the Google sign-in, not Continue with Google. Set a password from the email TP-Link sends, then enter that password here. A wrong password uses one of the router’s login attempts. The password stays in a file on this PC.
